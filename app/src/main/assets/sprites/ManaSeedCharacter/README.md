# Mana Seed Character – Uploadbereich

Hier kommen die neuen Charakter-Sprite-Sheets von Seliel the Shaper hinein.
Quelle: https://seliel-the-shaper.itch.io/character-base

Bitte die Originaldateinamen und Unterordner beibehalten. PNG-Sheets (und bei Bedarf die zugehörigen Aseprite-Dateien) hochladen, damit die Layer 0bas, 1out, 2clo, 3fac, 4har, 5hat, 6tla und 7tlb sowie die Animationsseiten korrekt zugeordnet werden können.

Die alten Spieler-Sprites bleiben bis zur erfolgreichen Umstellung erhalten. Die Integration beginnt erst nach Bestätigung des Uploads.

Hinweis: Lizenzbedingungen des Asset-Pakets beachten, insbesondere bei öffentlich zugänglichen Repositories.
