# Sprites

Lege hier deine PNG-Sprites und Sprite-Sheets ab.

Empfohlen: `black_grouse_idle_front.png`, `black_grouse_walk_front.png` usw.

Aseprite-Dateien können hier ebenfalls als Quelldateien gespeichert werden, müssen für die Android-App aber als PNG exportiert und im Spielcode geladen werden.
